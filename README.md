# Punch Mentality MVP

Pilot website for Punch Mentality — a Los Angeles coach-supervised sparring network and digital fighter portfolio.

## Pilot scope
- 18+ public registration
- Controlled / technical sparring
- Coach-approved matchmaking
- On-site weigh-in and check-in
- Professional footage
- Manual review of every application
- Private/share/public footage modes planned for session delivery

## Registration
The pilot application posts through FormSubmit to the founder email. The first live submission requires email activation from FormSubmit.

## Local
```bash
npm install
npm run dev
```
